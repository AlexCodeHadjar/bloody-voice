# Проверка проекта

Всё одной командой из корня проекта (Git Bash):

```bash
tools/check_all.sh                         # импорт + тесты (минимум перед коммитом)
tools/check_all.sh --balance               # + отчёт бота: 200 боёв на каждую тварь
tools/check_all.sh --shots "<абс. папка>"  # + автоснимки экранов (меню, карта, бой)
```

Godot берётся из `$GODOT`, по умолчанию `/d/Godot_v4.7.2-stable_win64_console.exe`.

## Как читать результат

- **Тесты**: строка `N tests, 0 failures`. Любой `FAIL` или `SCRIPT ERROR` — работа не готова, чини причину (не тест).
- **Импорт упал** — обычно новый скрипт не компилируется (строгая типизация: `untyped_declaration` = ошибка)
  или ресурс битый. Запусти импорт без фильтра и смотри первую ошибку.
- **Контент**: если игра стартует с экраном «Content errors», там список ошибок валидатора с файлом и полем.
- **Баланс** (`--balance`): колонки win% / turns / hp_left / parts. Ориентиры — в скилле `bv-balance`.
- **Скриншоты** (`--shots`): маршрут задан в `core/dev/dev_shots.gd` (01 меню … 08 итог боя). Открой PNG
  и посмотри сам — тесты не видят наложений, обрезанного текста и пустых мест. Для нового экрана добавь шаг
  в `dev_shots.gd`.

## Точечно

```bash
G=/d/Godot_v4.7.2-stable_win64_console.exe
"$G" --headless --path . -s res://tests/run_tests.gd -- --only=combat   # один набор
"$G" --path .                                                            # поиграть руками
```

Скриншоты кладёшь во временную папку (scratchpad), не в проект.
