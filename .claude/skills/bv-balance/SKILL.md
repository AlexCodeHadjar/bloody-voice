# Баланс

## Замер

```bash
G=/d/Godot_v4.7.2-stable_win64_console.exe
tools/check_all.sh --balance                                                    # 200 боёв на тварь
"$G" --headless --path . -s res://tests/bot/autoplay.gd -- --fights=200 --capture  # с картой поимки
```

Колонки: `win%` побед, `turns` ходов, `hp_left` HP охотника после победы (из 40), `parts` сломано частей,
`escaped` — тварь ушла по лимиту ходов. Бот — `core/dev/combat_bot.gd`: честный, видит только то, что игрок.

## Ориентиры со стартовой колодой — ЧЕРНОВИК

Предложены исполнителем, **владелец их ещё не утвердил** — перед большой перенастройкой спроси.

| Ранг | win% | hp_left | Смысл |
|---|---|---|---|
| A | 95–100 | 25–38 | обучающие |
| P | 70–95 | 8–25 | основная угроза |
| D | 15–35 | любой | босс, нужен апгрейд снаряжения |

Сейчас вне коридора: `vigil_hound` и `clay_saint` (~97–98%). Ориентиры поменяются со снаряжением (этап 2)
и прокачкой (этап 6) — тогда обнови таблицу.

## Подкрутка

```bash
python tools/tune_monsters.py data/monsters/mvp.json '{"lamplighter": {"hp": 62, "intents": 2, "grasp": [8]}, "rust_mantis": {"double_cut": [3, 2]}}'
```
Меняет HP, число действий за ход и **первый** эффект урона/блока/лечения/рассудка в ходе (`[amount]` или
`[amount, hits]`). Стаки статусов — руками в JSON. Текст хода в данных не хранится: игра строит его из эффектов
(`core/content/effect_text.gd`), так что он всегда совпадает с числами.

## Чему научил первый проход

- Тварь с 1 действием за ход почти весь урон отдаёт в блок — давление создаёт число действий, а не большой урон.
- Кровотечение складывается: два «кислотных» хода за ход быстро убивают.
- Поломка частей может сделать тварь опаснее: в колоде остаются только сильные ходы.
- Меняй по одной-две вещи за прогон: 200 боёв дают разброс около ±3%.

Результаты прогона — в сообщение коммита.
